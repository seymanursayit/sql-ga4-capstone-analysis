# SQL & GA4 Capstone Analysis

## Overview

This project was completed as part of the GoIT Data Analyst training program. It focuses on analyzing digital advertising performance and e-commerce user behavior using PostgreSQL, Google BigQuery, and Google Analytics 4 (GA4).

The project combines SQL techniques to analyze marketing campaigns, evaluate advertising performance, prepare analytical datasets, and measure e-commerce conversion funnels.

## Tools & Technologies

- PostgreSQL
- Google BigQuery
- Google Analytics 4 (GA4)
- DBeaver
- SQL

## Project Tasks

### Part 1: Online Advertising Campaign Analysis (PostgreSQL)

Analysis of Facebook Ads and Google Ads data using the following tasks:

1. Daily advertising spend statistics – average, maximum, and minimum spend.
2. Top 5 days by overall Return on Marketing Investment (ROMI).
3. Identification of the campaign with the highest weekly conversion value.
4. Monthly campaign reach growth analysis.
5. Identification of the longest continuous advertising activity period for an ad set.

### Part 2: E-commerce Data Analysis (BigQuery & GA4)

Analysis of Google Analytics 4 e-commerce event data:

1. **Event Data Preparation:** Extracting user, session, traffic source, device, and event information.
2. **Conversion Funnel Analysis:** Calculating session-to-cart, session-to-checkout, and session-to-purchase conversion rates.
3. **Landing Page Performance:** Comparing purchase conversion rates across different landing pages.
4. **User Engagement & Purchase Correlation:** Analyzing the relationship between user engagement, engagement time, and purchase behavior.

## SQL Concepts Applied

- Common Table Expressions (CTEs)
- UNION ALL and JOIN
- Aggregate functions
- Date and time functions
- Window functions (LAG, ROW_NUMBER)
- Conditional expressions (CASE, IF)
- NULL handling

- Conversion rate calculations
